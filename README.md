# Casals de Gent Gran · Sant Pere de Ribes

Aplicació de gestió dels casals de Ribes i Roquetes (Fundació Ave Maria).

- Web: GitHub Pages (aquest repositori).
- Usuaris, contrasenyes i dades: Supabase (servidor a la UE).
- Els permisos de cada perfil es comproven a la base de dades.

Aquest repositori no conté dades ni contrasenyes. La clau de `config.js` és la clau pública de Supabase.
No hi posis mai la clau `service_role` / `secret`.
